Данный проект предназначен для дообучения уже готовой модели XLM-RoBERTa под задачу классификации заявок технической поддержки

Модель выполняет многозадачную классификацию:

- определяет, в какие отделы следует направить заявку;
- предсказывает значения дополнительных категорий, например тип, сервис или приоритет заявки.


Маршрутизация рассматривается как многометочная задача: одной заявке могут соответствовать несколько отделов. Для каждой дополнительной категории модель выбирает один класс.
Проект также поддерживает экспорт модели в формат ONNX.
